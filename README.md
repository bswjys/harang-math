# 공부하랑핑 💖

김하랑(초등 1학년)의 수학 공부 웹앱. 문제를 풀면 감(🍊)이 하나씩 쌓이고, 100개를 모으면
엄마 아빠에게 소원을 말할 수 있어요.

## 쓰는 법

- 폰 브라우저에서 주소를 열고 **홈 화면에 추가**하면 앱처럼 전체 화면으로 열려요. (인터넷이 없어도 열립니다)
- 문제를 고르면 바로 채점되고, **맞히든 틀리든 해설이 항상** 나와요.
- **맞히면** 감 1개가 바로 쌓이고, **틀리면** 감이 깎이지 않아요. 해설을 읽고 `다시 풀어보기`로 맞히거나,
  `알겠어요! 다음 문제`로 넘어가면 **노력 감 1개**를 받아요.
- 위쪽 `🍬 그림 힌트 보기`를 누르면 사탕·딸기 그림으로 생각할 수 있게 도와줘요.
- 카드 아래 **`◀ 이전 문제`** 로 방금 푼 문제를 다시 볼 수 있어요(정답·해설 그대로, 감은 다시 안 줘요). `다음 문제 ▶`로 돌아와요.
- **`🗣️ 읽어주기`** 를 누르면 문제를 소리 내어 읽어 줘요. 다시 누르면 멈추고, 다음 문제로 넘어가도 자동으로 멈춰요.
- 위쪽 **`🎯 오늘 미션 0 / 5`** 은 하루 5문제 목표예요. 5문제를 채우면 별 5개와 축하 배지가 나오고, 날짜가 바뀌면 저절로 새로 시작해요.
- 틀린 문제는 **`🌸 헷갈린 문제 (N)`** 에 모여요. 눌러서 그 문제만 다시 풀고, 맞히면 오답 목록에서 **졸업**해요.
- 감 10개마다 칭호가 바뀌어요: `새싹` → `반짝` → `하트` → `별빛` → `무지개` → `공주` → `마법` → `보석` →
  `달빛` → `왕관` → `소원요정 하랑핑`(100개).
- 감 100개를 모으면 축하 팝업이 뜨고, 소원을 적거나 추천 소원을 골라 **소원 쿠폰함**에 저장해요.

## 엄마 아빠께 🎁

- 오른쪽 위 **🎁 소원 쿠폰함** 버튼을 누르면 아이가 적은 소원이 보여요.
- **`📊 리포트`** 버튼을 누르면 오늘/누적 푼 문제와 정답률, 오늘 미션 달성 여부, 단원별(덧셈·뺄셈·수/비교·시계·모양/규칙)
  정답률 막대, 그리고 **하랑이가 잘하는 것 / 조금 더 연습하면 좋은 것** 요약이 한 번에 보여요.
- 아이가 소원을 이뤘으면 **`소원 들어줬어요 ✅`** 를 눌러 주세요. 그다음 **`새로운 100개 도전 시작 🌱`** 을
  누르면 감이 0부터 다시 쌓이고 다음 소원을 준비할 수 있어요. (지난 소원 기록은 쿠폰함에 그대로 남아요)
- 오른쪽 위 **🔊 / 🔇** 로 효과음을 끄고 켤 수 있어요.
- 기록은 그 폰의 브라우저에만 저장돼요(서버로 보내지 않아요). 브라우저 기록을 지우면 함께 지워져요.

## 문제 종류 (초등 1학년 2학기 수준)

| 영역 | 내용 |
| --- | --- |
| 덧셈과 뺄셈 | 한 자리 수 덧셈, 10이 되는 짝, 10에서 빼기, 두 자리 수 − 한 자리 수, 세 수의 계산, 빈칸 채우기(□) |
| 100까지의 수 | 다음 수·앞의 수, 수 이어 쓰기, 10개씩 묶음과 낱개, 크기 비교(>, <, =), 10이 10개면 100 |
| 시계 보기 | 아날로그 시계 그림으로 `몇 시` / `몇 시 30분` |
| 모양과 규칙 | 도형 이름(동그라미·세모·네모), 되풀이 무늬의 다음 모양 |

## 파일 구성

```
index.html            화면
styles.css            디자인 (핑크 테마, 모바일·태블릿·PC 반응형)
app.js               문제 만들기·채점·감/칭호/소원·효과음·읽어주기·오답 복습·리포트
fonts/HarangSans.woff  한글 폰트(Noto Sans KR 일부 글자, OFL)
icons/               앱 아이콘 (192/512/180/1024, maskable)
manifest.webmanifest  홈 화면에 추가용
sw.js                오프라인 캐시
tools/make_icons.py  아이콘 다시 만들기
.dev/test_app.py     Playwright 자동 검증 (모바일·태블릿·PC·오프라인)
```

## 검증

```
python3 .dev/test_app.py
```

모바일 390px·태블릿 820px·PC 1280px에서 문제 풀이, 정답 응원·오답 격려와 해설, 감 적립과 진행바,
감 100개 소원 팝업·쿠폰 저장·부모 확인·새 도전, 효과음 토글, 새로고침 유지, 콘솔 오류 0건,
가로 넘침 0, 오프라인 실행에 더해 새로 넣은 5가지 기능을 확인합니다.

- `◀ 이전 문제` 로 돌아가도 정답·해설이 그대로 보이고 감이 중복 지급되지 않는지
- `🗣️ 읽어주기` 가 ko-KR 문제 문장을 읽고, 다시 누르거나 다음 문제로 넘어가면 멈추는지
- `🎯 오늘 미션` 이 4/5에서 5/5가 되며 별 5개와 축하 토스트가 뜨는지
- `🌸 헷갈린 문제` 에 오답이 쌓이고, 복습 모드에서 맞히면 졸업하며 0개가 되는지
- `📊 리포트` 의 단원별 집계가 저장된 정답률과 일치하는지

(스크린샷은 `downloads/harang_math/`)
