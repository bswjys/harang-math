# 공부하랑핑 💖

김하랑(초등 1학년)의 **수학·받아쓰기·영어** 공부 웹앱. 문제를 풀면 감(🍊)이 하나씩 쌓이고, 100개를 모으면
엄마 아빠에게 소원을 말할 수 있어요.

## 쓰는 법

- 위쪽 **`🔢 수학` / `✏️ 받아쓰기` / `🔤 영어`** 탭을 눌러 과목을 바꿔요. 한 번의 터치로 전환되고, 390px 폰에서도 한 줄에 들어가요.
- 감(🍊)·칭호·오늘 미션(5문제)·소원 100개는 **수학·받아쓰기·영어가 하나로 합산**돼요.
- 폰 브라우저에서 주소를 열고 **홈 화면에 추가**하면 앱처럼 전체 화면으로 열려요. (인터넷이 없어도 열립니다)
- 문제를 고르면 바로 채점되고, **맞히든 틀리든 해설이 항상** 나와요.
- **맞히면** 감 1개가 바로 쌓이고, **틀리면** 감은 **0개** 그대로예요(틀려서 감이 올라가는 일은 없어요).
  해설을 읽고 `다시 풀어보기`로 **맞히면** 그때 감 1개를 받아요.
- 위쪽 **`🍊 0 / 100` 감 배지**를 누르면 **감이 화면 위에서 우수수 떨어져요**. 크고 작은 감이 빙글빙글 돌며
  좌우로 흔들리면서 내려오고, 연속으로 누르면 더 많이 쏟아져요(최대 180개까지 — 느려지지 않아요).
  눌러도 감 개수는 그대로이고, `감 비가 주르륵~ 🍊 지금 7개!`, `통통통! 소원까지 93개 남았어! ✨` 같은
  짧은 응원 토스트와 가벼운 효과음이 나요.
- 위쪽 `🍬 그림 힌트 보기`를 누르면 사탕·딸기 그림으로 생각할 수 있게 도와줘요.
- 카드 아래 **`◀ 이전 문제`** 로 방금 푼 문제를 다시 볼 수 있어요(정답·해설 그대로, 감은 다시 안 줘요). `다음 문제 ▶`로 돌아와요.
- 위쪽 **칭호 배지(`🌱 새싹 하랑핑`)** 를 누르면 **🧚 핑크 요정**이 말풍선으로 응원해 줘요
  ("하랑아 화이팅! 🌟", "열심히 해! 할 수 있어 💪" …). 배지나 빈 곳을 터치하면 닫혀요.
- 위쪽 **`🎯 오늘 미션 0 / 5`** 은 하루 5문제 목표예요. 5문제를 채우면 별 5개와 축하 배지가 나오고, 날짜가 바뀌면 저절로 새로 시작해요.
- 틀린 문제는 **`🌸 헷갈린 문제 (N)`** 에 모여요. 눌러서 그 문제만 다시 풀고, 맞히면 오답 목록에서 **졸업**해요.
- 감 10개마다 칭호가 바뀌어요: `새싹` → `반짝` → `하트` → `별빛` → `무지개` → `공주` → `마법` → `보석` →
  `달빛` → `왕관` → `소원요정 하랑핑`(100개).
- 감 100개를 모으면 **🧚 요정이 반짝이와 함께 나타나** 크게 칭찬하고(`우와~ 100개 다 모았어! 정말 잘했어요!`),
  **`소원 말하러 가기 🎁`** 로 바로 소원 적기·선물 받기로 이어져요.
- 소원을 저장해 **선물 쿠폰이 만들어지면 감이 바로 `0 / 100`으로 리셋**되고 새 100개 모으기가 시작돼요.
  누적 총 감·오늘 푼 문제·콤보·소원 쿠폰·과목별 리포트 기록은 그대로 남아요.

## ✏️ 받아쓰기

- 급수를 고르면 10문장씩 나와요. **1~8회(80문장)** 에 **연습 1~3(30문장)** 을 더해 모두 110문장입니다.
- **`🔊 보통 속도로 듣기`** 와 **`🐢 천천히 듣기`** 두 가지로 들려줘요. 다시 누르면 멈춥니다.
  미리 녹음한 **또렷한 여자 목소리 MP3**(110문장, `audio/dict/`)를 재생해서 기기·브라우저마다 목소리가 달라지지 않아요.
  천천히 듣기는 같은 목소리를 0.72배로 들려줘요. (MP3 재생이 안 되는 브라우저에서만 기기 음성으로 대신 읽어요)
- **`✍️ 공책에 쓰기`**: 공책에 쓴 다음 `정답 보기`를 누르면 원고지 칸으로 정답·띄어쓰기·팁이 나오고,
  `⭕ 맞았어요!` / `❌ 다시 연습할래요` 로 스스로 채점해요.
- **`⌨️ 직접 치기`**: 입력하고 `채점하기`를 누르면 바른 문장과 내가 쓴 문장을 글자 단위로 비교해
  **틀린 글자를 빨갛게** 보여 주고, 팁도 함께 알려 줘요. 마침표만 빠뜨리면 맞은 것으로 채점하면서
  "문장 끝에 마침표를 찍어요" 하고 알려 줘요.
- 10문장을 다 채점하면 축하 배너와 꽃가루가 나와요.
- 틀린 문장은 **`🌸 틀린 문장 복습 (N)`** 에 모여 다시 해 볼 수 있어요.

## 🔤 영어 (초등 1학년)

4가지 코스를 골라 가며 풀어요. 모두 **4지선다**이고, 문제마다 **영어 듣기**와 **한 줄 해설**이 있어요.

| 코스 | 내용 | 문항 |
| --- | --- | --- |
| 🐾 **그림 영단어** | 그림(이모지)과 우리말 뜻을 보고 알맞은 영어 낱말 고르기 — 동물·과일·색깔·가족 | 24 |
| 🔊 **소리 듣고 찾기** | 영어 발음을 듣고 알파벳 대소문자(`A a`)·기초 단어 찾기 | 20 |
| 💬 **생활 영어 한마디** | “아침에 선생님을 만났어요” 같은 상황에 맞는 영어 표현 고르기 (`Good morning!`, `Thank you!`, `I love you!` …) | 16 |
| 🧩 **빈칸 알파벳** | `c ? t` + 🐱 고양이 → 빠진 알파벳 넣어 스펠링 놀이 | 16 |

- **`🔊 보통`(1.0배) / `🐢 천천히`(0.72배)** 로 들려줘요. 미리 녹음한 **귀여운 영어 여자아이 목소리 MP3**
  (76문항, `audio/eng/`, `en-US-AnaNeural`)라서 기기마다 목소리가 달라지지 않아요.
  (MP3가 재생되지 않는 브라우저에서만 기기 영어 음성으로 대신 읽어요)
- 정답이면 감 **+1**, 틀리면 **+0**. 해설에 발음·뜻을 쉽게 풀어 주고, `🔊 다시 듣기` 로 바로 다시 들을 수 있어요.
- 틀린 문제는 **`🌸 틀린 영어 복습 (N)`** 에 모여 다시 풀 수 있고, 맞히면 오답에서 **졸업**해요.

## 엄마 아빠께 🎁

- 오른쪽 위 **🎁 소원 쿠폰함** 버튼을 누르면 아이가 적은 소원이 보여요.
- **`📊 리포트`** 버튼을 누르면 오늘/누적 푼 문제와 정답률, 오늘 미션 달성 여부, **과목별(🔢 수학 / ✏️ 받아쓰기 / 🔤 영어) 정답률**,
  수학 단원별 정답률 막대, 받아쓰기 회차별 정답률, 영어 코스별 정답률, 그리고 **하랑이가 잘하는 것 / 조금 더 연습하면 좋은 것** 요약이 한 번에 보여요.
- 아이가 소원을 이뤘으면 **`소원 들어줬어요 ✅`** 를 눌러 주세요. 감은 소원을 저장할 때 이미 0/100으로
  새로 시작하므로, 아이는 바로 다음 100개를 모을 수 있어요. (지난 소원 기록은 쿠폰함에 그대로 남아요)
- 오른쪽 위 **🔊 / 🔇** 로 효과음을 끄고 켤 수 있어요.
- 기록은 그 폰의 브라우저에만 저장돼요(서버로 보내지 않아요). 브라우저 기록을 지우면 함께 지워져요.

## 문제 종류 (초등 1학년 2학기 수준)

**산수(덧셈·뺄셈) 문제가 80%**, 100까지의 수·시계·모양/규칙 같은 개념 문제가 **20%** 나와요.

| 영역 | 내용 |
| --- | --- |
| 덧셈과 뺄셈 (80%) | 한 자리 수 덧셈, 10이 되는 짝, 10에서 빼기, 두 자리 수 − 한 자리 수, **두 자리 수 덧셈(받아올림 없이)**, 세 수의 계산, 빈칸 채우기(□) |
| 100까지의 수 (8%) | 다음 수·앞의 수, 수 이어 쓰기, 10개씩 묶음과 낱개, 크기 비교(>, <, =), 10이 10개면 100 |
| 시계 보기 (6%) | 아날로그 시계 그림으로 `몇 시` / `몇 시 30분` |
| 모양과 규칙 (6%) | 도형 이름(동그라미·세모·네모), 되풀이 무늬의 다음 모양 |

모바일 390px·태블릿 820px·PC 1280px에서 문제 풀이, 정답 응원·오답 격려와 해설, 감 적립과 진행바,
감 100개 요정 칭찬·소원 저장·감 0/100 리셋·쿠폰 유지, 효과음 토글, 새로고침 유지, 콘솔 오류 0건,
가로 넘침 0, 오프라인 실행에 더해 아래를 확인합니다.

- `◀ 이전 문제` 로 돌아가도 정답·해설이 그대로 보이고 감이 중복 지급되지 않는지
- **틀리면 감 +0 · 맞히면 +1** 인지 — 수학 일반/오답 복습 · 받아쓰기 공책(`❌ 다시 연습할래요`)/타자 오답 ·
  받아쓰기 오답 복습, 그리고 오답 뒤 `알겠어요! 다음 문제`로 넘어가는 경우까지 모두 확인
- 상단 **감 배지**가 버튼이고, 누르면 캔버스에 감이 실제로 그려지고(픽셀 확인) 토스트가 뜨며
  연속으로 눌러도 180개를 넘지 않는지(성능 보호 — 180개에서도 프레임 시간이 유휴와 같음: 감 그림을
  한 번만 그려 복사하는 방식)
- 수학 카드에 `🗣️ 읽어주기` 가 없고, **칭호 배지**를 누르면 요정 응원/100개 칭찬이 뜨고 닫히는지
- 감 100개 → 소원 저장 → **감 `0 / 100` 즉시 리셋**, 누적 총 감·오늘 문제·콤보·쿠폰은 그대로인지
- 받아쓰기 MP3 **110개 파일 전수 존재(3KB 초과)** · 보통 1.0/천천히 0.72 재생·다시 눌러 정지
- 영어 **76문항 전부 보기 4개(중복 없음)·정답 포함**, MP3 76개 존재·문장 일치, 보통 1.0/천천히 0.72,
  정답 +1/오답 +0, 오답 복습 졸업, 리포트 3과목·영어 4코스 분리, 3과목 감·미션 합산, 새로고침 유지
- 상단 3개 탭이 390px 한 줄에 들어가고 넘침이 없는지
- 수학 출제 비율이 **산수 80% · 개념 20%** 인지(600문제 표본)
- `🎯 오늘 미션` 이 4/5에서 5/5가 되며 별 5개와 축하 토스트가 뜨는지
- `🌸 헷갈린 문제` 에 오답이 쌓이고, 복습 모드에서 맞히면 졸업하며 0개가 되는지
- `📊 리포트` 의 단원별 집계가 저장된 정답률과 일치하는지

(스크린샷은 `downloads/harang_math/`)
